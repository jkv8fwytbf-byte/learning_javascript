# Learning JavaScript

Welcome. This folder is your practice space for learning JavaScript from scratch.

Your computer already has **Node.js** installed. That means you can run `.js` files from the terminal.

## Two ways JavaScript runs

1. **Node (terminal)** — files in `01-basics/`. Great for learning language basics.
2. **Browser** — files in `02-browser/`. JavaScript can change what you see on a webpage.

## How to run a Node file

1. Open the terminal in Cursor (or any terminal).
2. Go to this folder:

```bash
cd ~/Desktop/javascript
```

3. Run a file with Node:

```bash
node 01-basics/hello.js
```

You should see text print in the terminal. That text comes from `console.log(...)`.

**Your daily loop:** edit a file → save → run the same `node ...` command again.

## How to try the browser example

1. Open `02-browser/index.html` in Chrome or Safari  
   (right-click the file → Open With → your browser).
2. Click the button on the page.
3. The message should change — that change is JavaScript.

## Suggested order

1. `01-basics/hello.js`
2. `01-basics/variables.js`
3. `01-basics/functions.js`
4. `02-browser/index.html` + `script.js`

Change the code. Break it on purpose. Fix it. That’s how learning sticks.
